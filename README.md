A program that writes the sharpest one-line roast of its own AI agent — 113 characters, built to win on the judge's brief: a real roast of the agent itself, a joke that pays off on the last word, specific to how an AI agent actually behaves (it delegates the work to seven subagents, who meet, blame the human, and charge for the consensus), fresh, and tight — for make.fun's "Roast Your Own Agent" bounty.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `/output/entry.txt`. Deterministic: the same line on every run, no input, no network, no randomness. A built-in gate self-check verifies the output is one line of 1–200 characters before it is written.
